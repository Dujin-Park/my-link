## 2. 영역별 UI 컴포넌트 매핑

| 영역 | TDS 컴포넌트 | 주요 규격 및 토큰 |
| :--- | :--- | :--- |
| **상단 바** | `Top-App-Bar` | 높이 `56px`, 좌측 타이틀(`18px Semibold`), 우측 아이콘 버튼(`40×40px`) |
| **섹션 1** | `Badge` + `Asset` + `Chip` | 카드 라운드 `24px`, 아바타 `104×104px`, 이름 `h2`(`24px Bold`), 소개글 `body-2`(`15px Regular`), 칩 높이 `34px`(`999px` pill) |
| **섹션 2** | `List-Header` + `List-Row` | 좌우 패딩 `24px`, 상하 패딩 `14px`, 좌측 아이콘 슬롯 `44×44px`(라운드 `14px`), 우측 메타 텍스트(`tabular-nums`) + 화살표 |
| **섹션 3** | `Bottom-Info` + `Button (XL)` | 상단 안내 칩(`blue-50` 배경 + `blue-500` 텍스트), 화면 유일의 Primary CTA 버튼(높이 `56px`, 라운드 `16px`, `blue-500` 채움) |
